# FORGE Web App

This folder is a standalone Progressive Web App package.

## Android / Chrome
1. Host this folder on HTTPS (GitHub Pages is suitable).
2. Open the hosted URL in Chrome.
3. Choose "Install app" / "Add to Home screen".

## iPhone / iPad
1. Host this folder on HTTPS.
2. Open the hosted URL in Safari.
3. Tap Share → Add to Home Screen.

## Important
The app stores its working state in the browser's localStorage. Use FORGE's export/backup feature before clearing browser data or changing devices.

## GitHub Pages
Upload the contents of this folder to a repository (or the repository root), enable GitHub Pages, then open the Pages URL on your phone.
